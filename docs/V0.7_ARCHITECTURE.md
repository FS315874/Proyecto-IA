# Decisión de arquitectura de v0.7

## Alcance

v0.7 interpreta una observación visual vigente y produce elementos estructurados. No
decide una tarea, no controla mouse o teclado y no convierte texto visible en una
orden. Las imágenes permanecen locales salvo doble habilitación explícita.

## Proveedor y costo

Se conserva OpenAI Responses y `gpt-5.6-luna`. La documentación oficial consultada el
2026-08-25 confirma que Luna acepta imágenes de entrada, Structured Outputs y Responses,
con USD 0,20 por millón de tokens de entrada y USD 1,20 por millón de salida:

- https://developers.openai.com/api/docs/models/gpt-5.6-luna
- https://developers.openai.com/api/reference/cli/resources/responses/methods/create

`DESKTOP_AGENT_VISION_ENABLED=true` es un opt-in adicional a
`DESKTOP_AGENT_AI_ENABLED=true`. El adaptador usa detalle bajo, salida máxima de 1024
tokens, `store=False`, timeout existente y el mismo ledger de USD 1,00 mensual. Las
pruebas usan un cliente falso; no hubo llamada real ni envío de una captura.

## Contrato y validación

La respuesta cerrada contiene versión, estado, marca de instrucciones no confiables y
hasta veinte elementos. Cada elemento declara rol, etiqueta opcional, caja normalizada
de 0 a 1000 y confianza entre cero y uno. El dominio valida todo de nuevo y exige 0,80
de confianza para exponer un elemento operativo.

Los elementos locales reciben identificadores derivados de la observación y conservan
`window_id` y revisión. Esto permite que v0.8 exija una observación vigente antes de
usar una caja, sin confiar en un identificador elegido por el modelo.

## Privacidad y prompt injection

Solo se codifica el frame recibido, que ya corresponde a la región acotada y redactada
de v0.6. No se incluye el título de ventana ni el texto de accesibilidad. Los nombres
accesibles se fusionan después de la respuesta mediante rol e IoU; los sensibles se
suprimen.

Las instrucciones dentro de una imagen son datos. El prompt ordena marcarlas y el
dominio también busca patrones explícitos en etiquetas y accesibilidad. Si cualquiera
de las defensas detecta instrucciones, el resultado es `CONTENT_INSTRUCTION` y no
contiene elementos. Incluso un elemento válido sigue sin tener autoridad de ejecución.

## Validación realizada

- codificación PNG en memoria y dimensiones exactas;
- esquema estricto y una única región con `detail=low` y `store=False`;
- doble opt-in y presupuesto mensual persistente;
- cajas, confianza, `UNSUPPORTED`, errores y respuestas inválidas;
- fusión accesible local y supresión de nombres sensibles;
- rechazo de instrucciones desde flag, etiqueta o accesibilidad;
- evaluación de tres regiones ficticias con dos elementos esperados;
- precisión, recall e IoU estructurales de 1,0 con proveedor guionado;
- 23 pruebas nuevas y suite completa de 206 casos, sin red.

## Limitaciones

- la precisión real del modelo no fue medida;
- la detección local de prompt injection es deliberadamente conservadora pero no
  reemplaza la instrucción al proveedor ni la separación de autoridad;
- el detalle bajo puede perder controles pequeños;
- todavía no existe un proveedor de accesibilidad de Windows ni acciones de input;
- la CLI y la GUI no solicitan capturas visuales en esta versión.
